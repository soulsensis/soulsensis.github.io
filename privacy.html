soulsensis studio privacy policy

Last updated 21 October 2026.

soulsensis studio is a private desktop tool used only by the soulsensis writer to publish their own videos to their own YouTube channel and Instagram account. It has no other users.

YouTube API Services

soulsensis studio uses YouTube API Services. By using it, its user agrees to be bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What it accesses

With the account owner's permission (Google sign-in), the tool uses the YouTube Data API to upload the owner's videos, set their titles, descriptions, thumbnails, captions and playlists, schedule when they go public, and post the first comment on them. It reads only what it needs to do this, such as the channel's own playlists.

What it stores

The sign-in token is stored only on the owner's own computer, in a private settings file. Nothing is sent to any server run by soulsensis. No data about viewers or any other person is collected, stored, sold or shared.

Google user data

soulsensis studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The data is used only to publish the owner's own content, never for advertising, and is never transferred to anyone else.

Cookies

soulsensis studio is a desktop tool; it places no cookies and uses no tracking of any kind.

Removing access and deleting data

Access can be removed at any time at myaccount.google.com/permissions; the stored token can then no longer be used. The token can also be deleted at any time by removing it from the tool's settings file on the owner's computer. Besides the token, the tool keeps only the ids and links of the videos and playlists it created on the owner's own channel (so later videos join the same playlists and each Short can link to its full essay); deleting the tool's data folder deletes them.
